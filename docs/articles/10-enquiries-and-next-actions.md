# Turning an open enquiry into a specific next action

Mohammed Sheikh-Noor · 25 October 2026 · Prepared with AI assistance.

An overview count is useful only if staff can find the work behind it. Dealer Desk makes the open-enquiry count a link to the open list, and each enquiry number links to its exact record.

The overview shows the customer name, linked vehicle, question and next action. When no incomplete follow-up exists, it says No next action scheduled. Scheduled tasks are distinguished as overdue, due today or upcoming using the dealership date in Europe/London.

The saved local workflow used Alex Morgan asking to view the Ford Puma. Staff opened enquiry #2, scheduled an availability check from that enquiry and completed the internal task. Reloading confirmed that the task and its relationship were saved.

Completing the check did not close the enquiry or send a reply. The still-open enquiry returned to the unscheduled attention list. Email, WhatsApp, SMS delivery and a conversation history are not connected. The interface must distinguish an internal action from a customer communication.
